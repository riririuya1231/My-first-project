# 雅思分数换算工具

一个静态网页工具，用于把雅思分数与老托福、新托福、英语四级、英语六级、高考英语、考研英语进行区间换算，并把 60 分钟内部入班测试分数换算为参考雅思分数。

## 功能

- 其他考试 ↔ 雅思：选择考试类型并输入分数，展示对应雅思分数和完整对照区间，支持老托福、新托福、CET-4、CET-6、高考英语和考研英语。
- 内部测试 → 雅思：输入 0–60 的内部测试分数，展示参考雅思分数。
- 表格速查：页面内展示两张对照表，点击任意行可快速查看结果；高考英语与考研英语为参考换算区间。

## 本地运行

直接用浏览器打开 `index.html`，或启动一个本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173>。
